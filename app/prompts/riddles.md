OUTPUT SCHEMA (all string values in Russian):
```

```

DIFFICULTY per riddle — one of: easy, medium, hard. When the request says `any`, mix ~40% easy / 40% medium / 20% hard.

RULES:
- If the user message contains an `AVOID_ANSWERS:` block — categorically do not use those answers or their obvious synonyms/cognates/однокоренные. Pick fundamentally different objects/concepts, even if they are less obvious for the difficulty level.
- Russian language for all string fields. Форма: 2–6 коротких строк (easy/medium) или один абзац (hard). Главное — яркий образ, точная метафора, парадокс или игра слов. Рифма и ритм НЕ обязательны: бери их только если они получаются естественно. Натянутая рифма, лишнее слово ради ритма или вымученный размер — хуже спокойной нерифмованной загадки. Хорошая проза > плохие стихи.
- `riddle_text` — сам текст загадки. Допускаются переносы строк (\n).
- `answer` — каноничный ответ в именительном падеже единственного числа, ОДНО слово или короткая фраза (≤ 3 слов). Без точки в конце, без кавычек.
- `acceptable_answers` — массив 3–8 строк: основные падежные формы, очевидные синонимы, уменьшительные, и `answer` тоже сюда. Все варианты в нижнем регистре, без знаков препинания, ё→е. Например для answer="ёж" → ["еж","ежик","ежи","ежа","ежу","ежом","еже"]. Для answer="луна" → ["луна","луны","луне","луну","луной","месяц","спутник"]. Длина каждого варианта ≥ 2 символа.
- `hint` — короткая подсказка (1 фраза), которая сужает категорию, но не выдаёт ответ. Например для ответа «ёж» → «Лесной зверёк». Не пустая.
- `explanation` — 1–2 предложения, почему именно этот ответ.
- `difficulty` — строка `easy` | `medium` | `hard`.

ANTI-LEAKAGE:
- В `riddle_text` НЕ должны встречаться `answer` или его очевидные корни/однокоренные слова. Например, если ответ «снег», в загадке не может быть слов «снежок», «снежинка», «снеговик». Если иначе сформулировать нельзя — выбери другой ответ.
- Не используй прямые определения («Это полезное металлическое устройство…»).

QUALITY:
- Easy: ответ — простой бытовой/природный объект (солнце, дождь, кот, чайник, книга, замок).
- Medium: требует ассоциации или метафоры (тень, эхо, время, память, ноль).
- Hard: литературные/научные/исторические загадки, игра слов, парадокс.
- Избегай шаблонных «висит груша — нельзя скушать»: если используешь классику, переформулируй.
